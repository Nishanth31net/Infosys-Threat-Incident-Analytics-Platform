# Infosys-Threat-Incident-Analytics-Platform


## 📌 Project Overview

This project presents an interactive **Power BI dashboard** for analyzing incident patterns, threat severity, geographical distribution, temporal trends, emergency response performance, security risks, and predictive intelligence.

The project was completed through **four milestones**, progressing from basic incident analytics to security risk assessment, predictive intelligence, and executive decision support.

## 🎯 Objectives

* Analyze incident patterns and severity levels.
* Identify geographical and temporal trends.
* Evaluate emergency response performance.
* Assess security risks and operational vulnerabilities.
* Predict emerging risks and incident trends.
* Support data-driven decision-making.

## 🛠️ Technologies Used

* **Microsoft Power BI**
* **DAX**
* **Microsoft Excel**
* **CSV Dataset**

## 📊 Project Milestones

### Milestone 1 — Basic Incident Analytics

* Data cleaning and preprocessing
* Data modeling and relationships
* KPI cards
* Incident and severity analysis
* Location and response analysis

### Milestone 2 — Threat & Geospatial Intelligence

* Threat classification
* Severity analysis
* City-wise analysis
* Geographical visualization
* Drill-through analysis

### Milestone 3 — Temporal & Response Analytics

* Monthly and seasonal trends
* Daily and weekly analysis
* Emerging threat analysis
* Response and resolution performance

### Milestone 4 — Security Risk & Predictive Intelligence

* Security risk assessment
* Operational vulnerability analysis
* Risk indicators
* Predictive threat analysis
* Incident forecasting
* High-risk zone identification
* Executive intelligence dashboard

## 📈 Dashboard Features

* Interactive KPI cards
* Charts and maps
* DAX-based calculations
* Drill-through analysis
* Dynamic slicers
* Risk assessment
* Predictive analysis
* Executive decision-support metrics

## 🔍 Key Insights

* Medium severity incidents are the most frequent.
* Accident is the most common incident type.
* Incidents are concentrated across monitored cities.
* Incident activity varies across different time periods.
* Response performance differs across teams, cities, and severity levels.

## 💡 Strategic Recommendations

1. Allocate additional resources during peak incident periods.
2. Improve response workflows in locations or teams with higher response times.
3. Continuously monitor emerging risk patterns using predictive analytics.
